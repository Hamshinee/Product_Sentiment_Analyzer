Product Sentiment Analyzer

Project Description

Product Sentiment Analyzer is a web application that analyzes product reviews and classifies them as positive, negative, or neutral using sentiment analysis techniques.

Features

- Analyze customer reviews
- Detect positive and negative sentiments
- User-friendly interface
- Fast sentiment prediction

Technologies Used

Frontend

- React.js
- HTML
- CSS
- JavaScript

Backend

- Python
- Flask

How to Run

1. Open the frontend folder and start the React application.
2. Open the backend folder and run the Flask server.
3. Connect the frontend with the backend.
4. Enter a review and analyze the sentiment.
